# Reload SEO tracker

Updated: 2026-10-18. Status: released to main on 2026-10-18 (owner-approved). After each deploy run `node scripts/indexnow.mjs`. Update this file whenever search-facing routes, content, metadata, tracking or indexing change. GEO.md tracks AI-search decisions.

## Approved decisions

- Arabic first for Saudi/GCC merchants; English remains independently available for future expansion.
- Stable public URLs: `/ar`, `/en`, and matching `/pricing`, `/faq`, `/how-it-works` children. Do not localize merchant, customer, OAuth, payment or API route contracts in this release.
- `/` remains an Arabic homepage alias with canonical `/ar`; preserve query/hash links and printed QR codes. Do not redirect by inferred visitor language. Language controls select equivalent URLs and retain query/hash.
- Canonical origin: https://www.reload.sa. Production apex redirects permanently to www with the path/query retained. Localhost is never redirected.
- Mirza explicitly requested leaving existing Salla wording unchanged while researching Make.com. This is a known content exception, not a new readiness endorsement. Do not silently change it or add new Salla availability promises to FAQs/schema.
- Regular approved pricing only. Private founding offers never appear in public HTML/schema. Do not expose credentials, customer/order information or staff records.
